# Силовой трекер — сборка APK в облаке GitHub

Компьютер с Android Studio не нужен. APK собирается на серверах GitHub (бесплатно) и скачивается на телефон по ссылке.

## Первая настройка (один раз, ~10 минут)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+ → New repository**. Имя — `trener`, отметьте **Private**, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** этой папки: `www`, `keystore`, `package.json`, `capacitor.config.json`, `README.md`. Нажмите **Commit changes**.
4. Папка `.github` скрытая и через перетаскивание часто не загружается. Создайте файл вручную: **Add file → Create new file**, в имени наберите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из этой папки (`.github/workflows/build.yml`) и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка запустится сама и займёт 5–8 минут. Зелёная галочка — готово.

## Установка на телефон

1. На телефоне войдите на github.com и откройте репозиторий → **Releases** (справа или внизу страницы) → последняя сборка → `silovoy-treker.apk`.
2. Откройте скачанный файл и разрешите установку из этого источника.

**Первый раз** ключ подписи отличается от старой версии, поэтому:
сначала в старом приложении «История» → «Сохранить копию» → удалить приложение → установить новый APK → «История» → «Восстановить».
Если у вас сохранился `debug.keystore` со старого компьютера (`C:\Users\<имя>\.android\debug.keystore` или `~/.android/debug.keystore`), замените им файл `keystore/debug.keystore` в репозитории — тогда даже первая установка встанет поверх.

## Как обновлять

1. В репозитории откройте папку `www` → **Add file → Upload files** → загрузите новый `index.html` (новый `silovoy-treker.html`, переименованный в `index.html`) → **Commit changes**.
2. Через 5–8 минут в **Releases** появится новая сборка — скачайте и установите поверх. Данные сохранятся.

Пересобрать без изменений: **Actions → Сборка APK → Run workflow**.

## Важно

- Репозиторий держите **приватным**: в нём лежит ключ подписи.
- Файл `keystore/debug.keystore` не удаляйте и не заменяйте — с другим ключом обновление поверх не встанет.
